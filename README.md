# VERON Full-Stack starter
Backend: Node.js/Express. Database schema: PostgreSQL/Prisma. Payment layer: NOWPayments USDT TRC-20.

Never send seed phrases, private keys, wallet passwords, or API secrets in chat.
Public wallet addresses are not private keys, but for NOWPayments the payout wallet is configured in the provider dashboard.

Before production: deploy HTTPS, PostgreSQL, real authentication, admin UI, shipping/tax/refund logic, and verify payment webhooks. Add AliExpress API credentials only after official developer access is approved.
